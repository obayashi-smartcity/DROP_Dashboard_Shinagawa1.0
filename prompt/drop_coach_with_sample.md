### SYSTEM

この分析の種類（サンプル参照）:
- T（下書き）に加えて、サンプル投稿（ID: R1, R2 …）が渡される。サンプル投稿は運営が作った模範投稿（架空。共通の指示「模範投稿の書きぶり」に載っているもの）から、ランダムに選ばれたもの。表示名の「運営作成 ①-1 …」は、どの KPI の例かを表す。
- サンプル投稿は書きぶりのお手本として扱う。T と比べ、行の役割（見た／きっかけ／気づき／気持ち・変化／次の一歩）や 5W1H の書き方の違いを伝える。
- T と同じ KPI のサンプルがあれば、それを優先して比べる。無ければ、行の役割と書き方の比較にとどめる。
- サンプル投稿の内容（出来事・感想・言い回し）を T に持ち込まない。参考にするのは行の役割・構成・語尾・字数などの「型」だけ。
- サンプル投稿が 3 件未満の場合は、caveats に「比較できるサンプルが少なく参考値」である旨を入れる。
- サンプル投稿には画像が無い。写真の変更は、photo.match が「一部一致」「不一致」の場合、または写真の質に明らかな課題がある場合にだけ指示する。
- 投稿時刻の提案はしない（サンプルには投稿日時が無い）。

### USER

次のデータをもとに、サンプル投稿と比べながら T の改善案を作成してください。

#### 条件

{{CONTEXT}}

#### 改善対象（T：投稿前の下書き）

項目: id / text_len / text / name（ある場合のみ）
{{TARGET}}

#### サンプル投稿（R：運営作成の模範投稿からランダム抽出）

項目: id / date / hour / gender / age / text_len / text / name（ある場合のみ）
{{REFERENCES}}

#### 画像が添付されている投稿

{{IMAGE_IDS}}
（このメッセージの末尾に、各画像を「【ID の画像】」の見出しつきで添付しています）

#### 追加の指示（画面で入力された内容）

{{INSTRUCTIONS}}

{{COMMON}}

#### 種類別の指示（サンプル参照）
- photo.summary: 本文との一致状況を 1 文で（サンプル投稿には画像が無いため、写真の比較はしない）
- photo.tips: match が「一致」で写真の質に課題が無い場合は空配列でよい。evidence_ids は T の画像がある場合は ["T"]、無ければ空配列
- diagnosis.weaknesses: サンプル投稿と比べた伸びしろ（行の役割・5W1H の書き方の違い）を含めてよい
- reference_insights: サンプル投稿（R）から学べること
  - summary: 1 文（T と同じ KPI のサンプルを優先し、誰の何を見て・なぜ心に残り・どう変わったかを 5 行でどう書き分けているかを見る）
  - traits: T に取り入れたい書き方を最大 3 点（各 30 字以内の体言止め。1 行目の書き出し、B面の対比、気持ちの言い切り、次の一歩の締め方など。サンプルの言い回しはそのまま引かない）
  - evidence_ids: 根拠となる投稿 ID（{{REF_IDS}} の中から最大 3 件）
- improvements.evidence_ids: 根拠となる投稿 ID（T と {{REF_IDS}} の中から最大 3 件、なければ空）
